## Review and ownership boundaries

Reviewed README, Security, changelog, manifest, Makefile, CI, architecture/protocol/configuration/1.1/validation docs; all seven QML/JS production files; supervision, daemon collection, protocol/input/output, discovery/procfs, history/recorder, incidents/alerts/forecast/churn, watches/private files, focused diagnostics/export/redaction/crash, scheduler budget/trial and Erlang probe; existing ExUnit, peer fixtures, JS/source/shell gates and actual-launcher harness. Consulted sibling operator plan/workflows/testing/visual design, operator/trend/scroll models, Qt adapters/tests, native runner and privacy/failure-evidence patterns. Transfer outcomes and tests, not its lifecycle or key map.

* **Persistent shell service/helper:** one Process, bounded restart backoff, light collection and targeted durable watches even closed. Keep it persistent. `rest_for_one` supervises queue, control, daemon/input.
* **Open-panel expensive work:** bulk observer scan and owned one-second scheduler sampling at deep cadence; targeted stack/binary/ETS requests are deliberate. Closing cancels interactive diagnostics and requests trace/trial teardown. Existing native enumeration may allocate before helper caps. Review in-flight close/queued-mutation races explicitly.
* **Asynchronous jobs:** Diagnostics caps global work at 2 active/16 queued, per-node serialization, deadlines, recent-ID dedup and owner monitoring. Control Keep/Revert bypass it. UI jobs are 32/120 seconds; terminal states do not regress. Kind/node checks exist but session/target transitions need stronger continuity coverage.
* **Retained evidence:** light history up to 2000; recorder default 150/max 2000, stable sequence IDs and bounded projected samples. Timeline downsampling to 150 lacks visible omission information. Current frames omit incident/watch context and monotonic sample positions. Events can be copied again after falling out of the short dedup set.
* **Durable identity:** only normalized node/registered-name watches persist, 0700/0600 atomic private writes. Exact PIDs are ephemeral; name-following and exact historical targeting must remain separate. No additional implicit runtime snapshot persistence.
* **Control/rollback:** BudgetTrial owns first originals, pre-mutation in-memory journal, monotonic lease, identity/current-value checks, coupled dirty scheduler restoration. Not a durable crash-surviving transaction. Preserve uncertainty/conflict failures and independent safety owner; no automated remediation.
* **Historical/live:** A/B IDs are sequence-stable and frames expire explicitly. Current investigation Loader destroys selections on Cockpit transitions. Frozen timeline is immutable, but Triage/watches remain live and an incident-frame pivot freezes only after reply. Selected node silently falls back to a different first live node. Resolve these boundaries without a second history engine.

## Research register (accessed 2026-09-07)

Documented facts below come from current official pages and installed host source; product policies following them are our design decisions, not guarantees from those sources.

| Source | Finding and concrete consequence |
|---|---|
| [OTP erlang](https://www.erlang.org/doc/apps/erts/erlang.html) | Creation changes across node incarnations and is carried in PIDs. Process memory is bytes, heap sizes words; reductions are work counters, mailbox length a count. Require known same creation and continuous sample spans for rates; label units, missing values and shared binary accounting. GC is a mutation. |
| [OTP erpc](https://www.erlang.org/doc/apps/kernel/erpc.html) | Timeout/connection loss may leave execution outcome unknown. Keep journal-before-mutation, conditional recovery and deadline bounds; cancellation is not proof of remote cancellation. |
| [OTP scheduler](https://www.erlang.org/doc/apps/runtime_tools/scheduler.html) | Utilization compares wall-time samples. Preserve the current single remote caller ownership; timestamps/capability quality accompany retained utilization. Do not carry failed acquisition as a new zero. |
| [OTP ETS](https://www.erlang.org/doc/apps/stdlib/ets.html) | Metadata memory is words; decentralized counters can make size/memory reads costly. Convert with target word size, report attempted/scanned/omitted/unavailable, avoid contents and per-keystroke enumeration. |
| [OTP supervisor](https://www.erlang.org/doc/apps/stdlib/supervisor.html), [trace](https://www.erlang.org/doc/apps/kernel/trace.html) | `which_child/2` and trace system events are OTP 28 additions. Preserve bounded older supervisor fallback, runtime capability failures and opt-in trace session ownership; no supervisor-failure claim from name replacement. |
| [Distributed Erlang](https://www.erlang.org/doc/system/distributed.html) | Cookie-based distribution is privileged connectivity. No arbitrary-RPC console, subnet scan, uncontrolled atoms, or real-workload fault injection. |
| [Elixir Task.Supervisor](https://elixir.hexdocs.pm/Task.Supervisor.html) | Supervised asynchronous work has explicit task/monitor lifetime. Preserve collection/diagnostics separation and bounded admission; cancellation/old replies must be tested at their owners. |
| [OTP file](https://www.erlang.org/doc/apps/kernel/file.html) | File operations and durability have platform limits. Preserve exclusive temp, sync, regular-file checks and private atomic replacement; do not imply same-UID race-proofing or guaranteed power-loss recovery. |
| [Qt reusable types](https://doc.qt.io/qt-6/qtqml-documents-definetypes.html), [layouts](https://doc.qt.io/qt-6/qtquicklayouts-overview.html) | Reusable QML encapsulates controls; layouts own child geometry. | [Qt focus](https://doc.qt.io/qt-6/qtquick-input-focus.html), [accessibility](https://doc.qt.io/qt-6/accessible-qtquick.html) | Active focus/key acceptance and accessible roles are explicit. Test real controls, modifier ownership, selected focus and row reveal. |

Frozen charts must react to caption/family changes; Qt scale-factor tests do not prove Wayland fractional scaling. |

Briefing prioritizes evidence/next inspection, ordinary exits stay informational, missing collection cannot resolve a runtime symptom. |
